# Журнал оцінок

Журнал оцінок групи з підрахунком середнього бала кожного студента.

Заліковий проєкт з курсу «Основи інформатики та програмування» (НТУ «ХПІ»). Тему й вимоги до залікового проєкту лектор ще не оголосив, тому на практиці П4 взято приклад «Журнал оцінок» із `ISSUES_STARTER.md`.

## Як запустити

```
git clone https://github.com/yurjjOne/grade-journal.git
cd grade-journal
python3 main.py
```

Тести: `python3 test_records.py`
